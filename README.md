# WebShop

Спецификация интернет-магазина и материалы лабораторных работ.

Ветка **4lab** — подключение хранилища: PostgreSQL 16 (схема 3НФ —
SQL-скрипты `4lab/src/api/db/`), EF Core для шести репозиториев и «сырой»
ADO.NET для заказов; все репозитории и контроллеры асинхронны. Подробности —
`4lab/README.md`.
